# Morrow — сайт кофейни

Демонстрационный одностраничный сайт для портфолио: спешелти-кофейня **Morrow** (React + TypeScript + Vite).

## Публичная ссылка

После деплоя сайт доступен по адресу:

**https://projectescape463-hash.github.io/Morrow/**

Деплой запускается автоматически при каждом push в `main` (GitHub Actions). В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Запуск локально

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Структура

- `src/components/` — секции страницы
- `src/data/content.ts` — меню, адрес, ссылки (удобно менять под реального клиента)
- `public/images/` — фотографии (Unsplash, локально)

## Перед передаче клиенту

1. Замените `TELEGRAM_URL` и адрес в `src/data/content.ts`.
2. Обновите тексты меню и часы работы.
3. Уберите или измените пометку в футере о демо-данных.

## Концепция

Редакционный минимализм с лёгким брутализмом: кремовый фон, чёрные правила, акцент терракоты, serif-заголовки и mono-навигация. Метафора — «утро начинается до будильника»: slow morning, не шаблонная кофейная сетка карточек.
