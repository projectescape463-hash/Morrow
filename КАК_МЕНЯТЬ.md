# Как менять содержимое сайта

Публичная ссылка: **https://projectescape463-hash.github.io/Morrow/**

После правок в GitHub (или `git push` с компьютера) сайт обновится за 1–2 минуты.

---

## Главный файл с данными

**`src/data/content.ts`** — почти всё, что видит посетитель:

| Что менять | Где в файле |
|------------|-------------|
| Telegram в шапке, hero, футере | `TELEGRAM_URL` |
| Telegram только в блоке «Как найти» | `CONTACT_TELEGRAM` |
| Адрес и карта | объект `ADDRESS`: `line`, `city`, `mapUrl`, `embedSrc` |
| Часы работы | массив `HOURS` |
| Напитки и цены | массив `DRINKS` |
| Десерты и цены | массив `DESSERTS` |
| Фото в галерее | массив `GALLERY` (`alt`, `caption`, имя файла в `publicAsset('images/…')`) |
| Большое фото на первом экране | `HERO_IMAGE` (через `publicAsset('images/hero.jpg')`) |

### Telegram

```ts
export const TELEGRAM_URL = 'https://t.me/ваш_ник'
export const CONTACT_TELEGRAM = 'https://t.me/DfF_gg'
```

### Адрес и карта

1. Откройте [Яндекс.Карты](https://yandex.ru/maps), найдите точку.
2. «Поделиться» → скопируйте ссылку → вставьте в `mapUrl`.
3. «Код карты» → iframe → атрибут `src` → вставьте в `embedSrc`.
4. Текст адреса — в `line` и `city`.

### Меню

Каждая позиция:

```ts
{ name: 'Капучино', note: 'описание', price: 280 }
```

### Картинки

1. Положите файл в **`public/images/`** (например `public/images/hero.jpg`).
2. В `content.ts` укажите имя через `publicAsset('images/hero.jpg')` — **не** пишите `/images/...` вручную, иначе на GitHub Pages картинки могут не открыться.

## Тексты на странице (заголовки, «О нас»)

| Раздел | Файл |
|--------|------|
| Первый экран | `src/components/Hero.tsx` |
| О кофейне | `src/components/AboutSection.tsx` |
| Заголовки меню / галереи | `MenuSection.tsx`, `GallerySection.tsx`, `VisitSection.tsx` |
| Подвал | `src/components/Footer.tsx` |
| Название вкладки браузера | `index.html` → `<title>` |

---

## Логотип и цвета

- Логотип: `src/components/Logo.tsx`
- Цвета, шрифты, отступы: `src/index.css` (переменные в `:root` в начале файла)

## Обновить сайт в интернете

```bash
cd morrow
git add .
git commit -m "Обновление контента"
git push origin main
```

GitHub Actions сам соберёт сайт и выложит на Pages.
